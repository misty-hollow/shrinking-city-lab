# 소리 QA — 스피커로 듣고 확인할 항목

이 문서는 사람이 실제 스피커로 직접 듣고 판단해야 하는 항목을 모은 것입니다.

**자동 검사로 이미 확인하는 것**(브라우저 QA, 오프라인 렌더)
- 한 조작·목표 달성의 최고 레벨이 −14 dBFS 아래인지
- 0.15초 간격으로 여섯 번 눌러도 한 번보다 3 dB 넘게 커지지 않는지
- 앞 조작의 남은 음 거두기
- 첫 입력 전에는 오디오를 열지 않는지

**사람만 판단할 수 있는 것**: 실제 스피커에서의 음량·질감·피로도·방 소음 속 들림.
기준은 설계안 6-16 소리 조항입니다. 방향은 "부드럽고 따뜻한 저녁 디오라마의 소리"이고, 소리는 정보를 더하지 않습니다.

## 1. 준비

- [ ] **전시에 쓸 스피커**를 씁니다. 노트북 내장 스피커로 전시한다면 내장 스피커로 듣습니다. 헤드폰으로도 한 번 들어 비교합니다.
- [ ] 운영체제 음량을 전시 때 설정할 값으로 고정하고, 그 값을 기록합니다(예: Windows 40%).
- [ ] 방 소음은 두 조건으로 듣습니다: 조용한 방 / 전시장 수준의 대화 소음(휴대폰으로 대화 소음을 틀어 두는 정도).
- [ ] 청취 파일을 만듭니다: dev 서버(`npx vite --port 5199 --strictPort --host 127.0.0.1`)를 띄우고 `node scripts/sound-audition.mjs`를 실행합니다. 그러면 `app/qa-shots/sound/index.html`에 장면 17개가 생깁니다. 음량 정규화는 하지 않았습니다.
- [ ] 두 사람 이상이 따로 듣고 기록합니다.

## 2. 장면별 청취 (qa-shots/sound/)

각 장면을 5점 척도로 매깁니다(1 = 거슬림 · 3 = 괜찮음 · 5 = 좋음). 3점 아래이면 이유를 한 줄 적습니다.

| 장면 | 들을 것 |
|---|---|
| 01 불씨 | 풀을 떠나는 소리가 작고 부드러운가. 딸깍이 없는가 |
| 02 등칸 1~5칸 | 칸이 올라갈수록 자연스럽게 이어지는가. 5칸이 과하게 밝지 않은가 |
| 03·04 +1 유구·우성 | 점등 → 빛 번짐 → 마을 도착이 하나의 사건으로 들리는가. 마을 음(많아야 4개)이 어수선하지 않은가 |
| 05 −1 | 꺼짐이 **경고음이 아니라 사그라짐**으로 들리는가(실패·벌 느낌이 없는가) |
| 06·07 기준 변경 | 15→20분, 15→10분이 서로 구분되지만 둘 다 부드러운가 |
| 08 목표 달성 | 짧고 따뜻한가. 과장된 축하(팡파르)로 들리지 않는가 |
| 09 막힌 조작 ×3 | 반복해도 귀가 아프지 않은가. 꾸짖는 느낌이 없는가 |
| 10 확정 · 11 고르기 ×3 | 확정이 또렷하되 크지 않은가. 고르기는 거의 들리지 않을 만큼 작은가 |
| 12 미션 1 브리핑 | 실제 10일(오르골 선율)과 가정 5일(속 빈 음)이 구분되는가 |
| 13·14 빠른 연타 | 5번·4번을 빨리 눌러도 쌓여서 커지거나 뭉개지지 않는가 |
| 15 소리 켜기 | 맑고 짧은가 |
| 16 움직임 줄이기 | 불씨·번짐 소리 없이 점등 음만 나도 어색하지 않은가 |
| 17 한 토막(약 14초) | 이어서 들었을 때 음악처럼 편안한가. 한 소리만 튀지 않는가 |

## 3. 실제 플레이에서 듣기 (10분 연속)

- [ ] 한 판(튜토리얼 → 미션 1·2·3 → S6)을 소리 켠 채 끝까지 합니다. **10분 뒤에도 거슬리지 않는가**(피로도 1~5).
- [ ] 소리와 화면이 맞는가. 점등 음이 등칸이 켜지는 순간과 맞는지, 마을 음이 빛이 닿는 순간과 맞는지 봅니다.
- [ ] 소리를 끄고 한 번 더 합니다. **소리 없이도 모든 정보가 화면에 있는가**(모르는 것이 생기면 기록합니다).
- [ ] 딸깍·지지직·끊김이 있는가. 있다면 언제인지(화면·조작) 적습니다. 저사양 기기에서 특히 봅니다.
- [ ] 첫 조작 전에는 소리가 나지 않는가(자동재생 규칙).
- [ ] [소리] 버튼으로 끄면 즉시 조용해지는가. 새로고침·90초 전시 복귀 뒤에도 끈 상태가 유지되는가.
- [ ] 전시장 소음 속에서 소리가 **들리지 않아도** 괜찮은가. 들리게 하려고 음량을 올려야 한다면 그 음량에서 다른 소리가 너무 크지 않은가.
- [ ] 여러 대를 나란히 전시한다면 옆 기기 소리와 섞였을 때 어수선하지 않은가.

## 5. 판단

- 3점 미만 장면이 있으면 그 소리만 다듬습니다. 소리가 나는 때(기능)는 바꾸지 않습니다.
- 10분 피로도가 3 미만이면 전체 음량을 낮추거나, 전시 기본값을 "소리 끔"으로 할지 결정합니다(사용자 결정).
- 딸깍·끊김은 기기·브라우저를 적어 버그로 남깁니다.
