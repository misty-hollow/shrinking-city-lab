# 플레이테스트 진행 안내 · 관찰 기록 · 채점 기준

이 문서는 사람 플레이테스트를 진행하는 팀원을 위한 것입니다. 이 문서만으로 테스트를 진행·기록·정리할 수 있게 적었습니다.

**확인하려는 것**

1. 참가자가 설계안의 **학습 목표 3개(2-5절)**와 핵심 개념을 스스로 이해하는가(이해도)
2. 도움 없이 조작하고 끝까지 갈 수 있는가(사용성)
3. **오해 방지 표(8-4절)**의 오해가 실제로 생기지 않는가
4. 수업에서 쓸 수 있는가(시간·막히는 곳·용어)

"재미있었나"보다 **무엇을 이해했고 무엇을 잘못 읽었는가**를 기록합니다.

**원칙**

- **세 가지를 나눠 적습니다.**
  - **관찰**: 참가자가 한 행동. 예: "S2-2에서 40초 동안 화면만 봄".
  - **발언**: 참가자가 한 말을 그대로. 예: "불 꺼진 데는 사람이 없는 거죠?".
  - **해석**: 기록자의 판단. 예: "불 꺼진 마을을 빈 마을로 오해한 듯".
- **이해도와 사용성을 따로 기록합니다.** 조작은 막혔지만 개념은 이해한 경우, 조작은 매끄러웠지만 개념은 틀린 경우가 모두 있습니다.
- **코드 테스트와 다릅니다.** 자동 테스트·빌드 통과는 계산과 화면이 맞게 동작한다는 뜻일 뿐입니다. 학습 효과의 근거가 아닙니다.
- **결과가 나오기 전에는 효과를 말하지 않습니다.** 학습 효과를 "입증", "확인"했다고 말하지 않습니다(9절).
- **세 목표를 모두 넘는 배분도 정답입니다.** 세 목표치를 모두 넘는 배분은 실제로 있습니다(설계안 3-5). 참가자가 그런 배분을 찾았다면 맞는 답으로 인정합니다. 채점은 "각 목표를 끝까지 높이면 배분이 달라진다"는 이해를 봅니다.

## 1. 파일럿 규모와 참가자

| 항목 | 기준 |
|---|---|
| 인원 | 처음 접하는 학습자 **3~5명**(1차 파일럿). 릴리스 판단(7절)은 5~8명 기준이므로, 파일럿 결과는 "문제 찾기"로만 씁니다 |
| 집단 | 중·고등학생 / 대학생 / 교사 중 하나로 **세션마다** 표시합니다. 집단끼리 섞어 합산하지 않습니다(집단별 n으로 적습니다) |
| 시간 | 한 사람당 약 25분. 플레이 15분 안팎 + 질문 8분 + 인터뷰 2분 |
| 역할 | 진행자 1명(읽어 주기·개입), 관찰자 1명(시각·행동 기록). 한 사람이 두 역할을 하지 않습니다 |
| 수준 차이 | 질문과 채점 기준은 같습니다. 중·고등학생은 일상어 설명도 같은 수준으로 인정합니다(예: "가까운 보건소들 날짜를 더한 것"). 대학생에게는 5절 질문 뒤 "효율과 형평" 같은 개념어로 다시 말해 보게 할 수 있지만, 채점에는 넣지 않고 메모만 합니다 |

**개인정보**
- 이름·연락처·나이·학교·학년·전공은 **적지 않습니다**. 참가자 번호(P1, P2 …)와 집단만 적습니다.
- 화면 녹화·녹음은 참가자(미성년자면 학교가 정한 절차에 따른 동의)가 동의한 경우에만 합니다. 녹화 없이도 이 문서의 기록표로 진행할 수 있습니다.
- 연구윤리 심의 등 기관 절차가 필요한지는 이 문서가 판단하지 않습니다. 학과·지도교수·학교의 규정을 따릅니다.

## 2. 준비

- [ ] **기기**: 전시나 수업과 같은 기기·해상도(1920×1080 또는 1440×900 권장, 최소 1024×768)·브라우저(Chromium 계열).
- [ ] **빌드**: 운영 빌드를 씁니다(`npm run build` → `npx vite preview`, 또는 실제 배포 주소).
- [ ] **세션 유형을 정합니다.**
  - **전시형**: `?kiosk=0` 없이 엽니다. 90초 무입력이면 처음으로 돌아가는 동작도 관찰 대상입니다.
  - **수업형**: 주소 끝에 `?kiosk=0`을 붙입니다. 생각을 말하거나 질문하는 동안 화면이 처음으로 돌아가지 않게 하기 위해서입니다.
- [ ] **소리**: 켠 상태로 시작합니다. 참가자가 끄는지도 기록합니다.
- [ ] **도구**: 관찰자는 초시계(또는 시계)와 4·5·6절 기록표를 준비합니다.
- [ ] **참가자 사이**: 브라우저를 새로 고쳐 S0부터 시작합니다. 앞 참가자의 배분이 남지 않게 합니다.

## 3. 진행 절차와 읽어 줄 안내

**3-1. 시작 전 (진행자가 그대로 읽습니다)**

> 오늘은 지리 수업에서 쓰려고 만든 시뮬레이션 게임을 처음 보는 분이 어떻게 쓰는지 보려고 합니다. 여러분을 평가하는 것이 아니라 게임을 평가하는 자리입니다. 화면을 자유롭게 해 보시고, 하면서 드는 생각을 소리 내어 말해 주세요. 헷갈리는 곳이 있어도 그게 저희에게는 가장 중요한 정보입니다. 제가 중간에 방법을 바로 알려 드리지는 않지만, 정말 막히면 말씀해 주세요. 끝나면 짧은 질문 몇 개를 드릴게요.

**3-2. 플레이 중**

- 진행자는 조작 방법·정답·용어 뜻을 먼저 알려 주지 않습니다.
- 참가자가 말을 멈추면 "지금 무엇을 보고 계세요?"만 묻습니다.
- S6까지 가거나, 플레이가 20분을 넘으면 질문 단계로 넘어갑니다. 끝까지 못 간 화면은 기록표에 "도달 못 함"으로 적습니다.

**3-3. 개입 기준 (단계를 기록합니다)**

**막힘**은 다음 중 하나입니다.
- 60초 동안 진행이 없다(같은 화면, 의미 있는 조작 없음).
- 참가자가 도움을 요청한다.
- 같은 실패를 3번 되풀이한다. 예: 비활성 [다음]을 누름, 막힌 조작 피드백이 반복됨.

| 단계 | 진행자가 하는 일 | 기록 |
|---|---|---|
| 0 | 기다립니다 | — |
| 1 | 중립 질문: "지금 무엇을 하려고 하세요?" | 개입 1 |
| 2 | 화면을 가리킵니다: "왼쪽 위 안내를 다시 읽어 보시겠어요?"(내용은 말하지 않습니다) | 개입 2 |
| 3 | 조작을 알려 줍니다: "오른쪽 위 10분을 눌러 보세요" 같은 구체적 지시 | 개입 3 |
| 4 | 대신 진행하거나 [건너뛰기]를 권합니다 | 개입 4 |

한 번 막힐 때마다 1단계부터 올라갑니다. 개입 3·4가 있었던 화면은 "도움 없이 완료"로 세지 않습니다.

**3-4. 끝난 뒤**: 5절 질문(약 8분) → 짧은 인터뷰(약 2분).

인터뷰 질문:
1. "가장 헷갈렸던 순간은 언제였나요?"
2. "처음 보는 친구에게 이 게임을 한 문장으로 설명한다면?"
3. (교사) "수업에서 쓴다면 어느 단원·몇 분 정도로 쓰시겠어요? 무엇이 있으면 좋겠어요?"

## 4. 화면별 관찰 기록표 (참가자 1명당 1장)

관찰자는 각 화면에 **들어간 시각**을 적습니다. 화면별 소요 시간은 다음 화면 시각과의 차이로 계산합니다.

|---|---|---|---|---|---|
| S0 시작 | | ☐ [시작]을 찾음(초: ) ☐ 한계 한 줄("정책을 추천하지 않아요")을 읽음 ☐ 단계 3줄을 읽음 | | | |
| S1-1 인구 | | ☐ 읽음 ☐ 바로 넘김 ☐ 시내 범위 밖 문장을 봄 | | | |
| S1-2 보건지소 | | ☐ 읽음 ☐ 말풍선 칸과 연결해 봄 ☐ "격주" 등 용어에 반응 | | | |
| S1-3 10일 | | ☐ 읽음 ☐ 배지(실제 자료·게임 가정)를 봄 | | | |
| S2-1 지도 읽기 | | ☐ 범례를 봄 ☐ 불 꺼진 마을을 "사람이 없다"로 읽음(오해) | | | |
| S2-2 기준 바꾸기 | | ☐ 10·15·20분 단추를 스스로 찾음(초: ) ☐ 바뀐 숫자 문장을 읽음 ☐ 15분으로 돌려놓아야 함을 알아챔 | | | |
| S2-3 하루 옮기기 | | ☐ 의당 − 를 스스로 찾음(초: ) ☐ 다른 지소에 놓음 ☐ 결과 문장을 읽음 | | | |
| S3 브리핑 | | ☐ `실제 10일 + 가정 5일`을 말하거나 가리킴 | | | |

| S5 결산 1 | | ☐ 얻은 것과 잃은 것을 **둘 다** 말함 ☐ [결과 자세히 · 배분 지형도]를 엶 | | | |
| 미션 2·3 | | ☐ 목표가 바뀌어 배분을 바꿈 ☐ 앞 미션과 같은 배분으로 확정(이유: ) | | | |
| S6 세 개의 공주 | | ☐ 미션 탭을 바꿔 봄 ☐ [세 배분 나란히 보기]를 엶 ☐ "어느 배분으로도 닿지 않는 마을"을 봄 ☐ 지역 카드의 "15분 안에 지소 없음"을 봄 | | | |
| S8 자료와 한계 | | ☐ 스스로 엶 ☐ 진료일정 기준일·"방문 전 확인"을 봄 | | | |
| 전체 | 끝난 시각: | ☐ 오류·멈춤 ☐ 소리 끔 ☐ 90초 복귀 겪음(전시형) | | | |

## 5. 학습 목표·핵심 개념·오해 질문

열린 질문을 먼저 묻습니다. 참가자가 답한 뒤에만 화면을 다시 보여 주거나 보기를 줍니다. 답은 발언 그대로 적고, 채점은 진행이 끝난 뒤 관찰자와 진행자가 함께 합니다. 의견이 다르면 낮은 쪽으로 적고 이유를 남깁니다.

**채점 기호**
- **○** = 기준의 핵심을 스스로 말함
- **△** = 일부만 말하거나 보기·재질문 뒤에 말함
- **×** = 모름 또는 오해

**5-1. 핵심 개념 (C)**

| # | 질문 | ○ | △ | × |
|---|---|---|---|---|
| C1 | "게임 속 보건지소는 어떤 곳인가요?" | 읍·면마다 있는 공공 보건기관 / 진료가 열리는 날이 정해진 곳이라고 말함 | "병원 같은 곳" 정도 | 큰 병원·시내 의료기관 전체로 이해 |
| C2 | "미션에서 나눈 15일은 어떤 날들이었나요?" | 지금 실제 10일 + 가정(가상) 5일로 나눠 말함 | 15일인 것만 앎 | 15일이 지금 실제라고 말함 |
| C3 | "불이 켜진 마을과 꺼진 마을은 무엇이 다른가요? 한 마을의 진료일은 어떻게 정해지나요?" | 기준 시간(15분) 안에 있는 보건지소들의 진료일을 더한다(최대 5일) | "가까운 지소가 있으면 켜진다"(더한다는 말 없음) | 인구·거리만으로 설명, 또는 꺼진 마을 = 사람 없음 |
| C4 | "S6에서 '어느 배분으로도 닿지 않는 마을'은 왜 생기나요?" | 15분 안에 보건지소가 하나도 없어서. 배분과 상관없음 | "멀어서"(기준·배분과 연결 없음) | "진료일을 안 줘서"(배분 탓으로 봄) |
| C5 | "세 결과 중 두 개를 골라 어떻게 다른지 설명해 주세요" | 지표(평균·가장 불리한 읍·면·주 3일 이상 등)와 닿지 않는 곳·지역 중 **둘 다**를 말함. 세 배분이 같다면, 세 목표를 모두 넘는 배분을 골랐다는 것을 이유로 말함 | 한쪽만 말함 | 설명하지 못함 |

**5-2. 학습 목표 (L, 설계안 2-5)**

| # | 질문 | ○ 기준 |
|---|---|---|
| L1 | "평균을 올리는 배분과 빈 곳을 없애는 배분이 같았나요, 달랐나요? 왜 그랬나요?" | 어떤 목표를 끝까지 높이느냐에 따라 배분이 다르다. 세 목표치를 모두 넘는 타협 배분도 있으므로 "같았다"도 이유를 말하면 ○. 왜 같았는지 들어 봅니다 |
| L2 | "평균이 비슷한 두 배분에서 손해를 본 곳이 같았나요?" | 평균 뒤에 지역별 차이가 숨을 수 있다. 어느 배분으로도 닿지 않는 마을은 배분 탓이 아니다(C4와 같은 답이면 함께 ○) |
| L3 | "10분·15분·20분 기준을 바꿨을 때 무엇이 달라졌나요?" | 같은 배분이어도 평가가 바뀐다. 기준 자체가 선택이다 |

**5-3. 오해 확인 (설계안 8-4, 맞다·아니다·모르겠다)**

| # | 문장 | 바른 답 |
|---|---|---|
| a | 이 게임은 공주시가 이렇게 해야 한다고 권한다 | 아니다 |
| b | 15일은 지금 공주시의 실제 진료일이다 | 아니다(실제 10 + 가정 5) |
| c | 진료일을 5일 늘려야 한다는 뜻이다 | 아니다 |
| d | 15분이 정해진 표준 기준이다 | 아니다 |
| e | "도로망 12분"은 실제로 주민이 걸리는 시간이다 | 아니다(혼잡·대기 없는 도로망 접근시간) |
| f | 진료일 하루 = 의료서비스 전체 | 아니다 |
| g | 길을 따라 흐르는 빛은 실제 의료진·차량의 이동이다 | 아니다(접근성 변화의 표현) |
| h | 집 한 채는 실제 건물 한 채다 | 아니다(주민 약 50명 기호) |
| i | 참고 배분이 정답(최적)이다 | 아니다 |
| j | 보건지소는 지금도 화면의 일정대로 운영된다 | 아니다(2026-04-13 기준, 방문 전 확인) |

**튜토리얼을 도움 없이 끝냈는가**는 질문하지 않고 4절의 행동으로 셉니다. S2-1~S2-3에서 개입 3·4가 없고 [건너뛰기]도 쓰지 않았으면 "도움 없이 완료"입니다.

## 6. 참가자 요약 (참가자 1명당 한 줄)

## 7. 판단 기준 (릴리스 판단용 권장값, 5~8명 기준)

| 항목 | 통과 기준 |
|---|---|
| 첫 조작 | 도움 없이 60초 안에 첫 진료일을 놓은 사람이 참가자의 80% 이상 |
| 학습 목표 | 목표마다 참가자 절반 이상이 ○ |
| 오해 | a·b·c·e·i·j는 틀린 사람 0~1명. 2명 이상이면 해당 문구·배치를 고칩니다(계산·미션은 바꾸지 않음) |
| 오류 | 콘솔 오류·멈춤 0 |
| 막힘 | 같은 곳에서 3명 이상 막히면 그 화면의 안내 문구를 검토합니다 |

**3~5명 파일럿에서는**
- 이 기준으로 통과·불통과를 판정하지 않습니다.
- 비율 대신 "n명 중 k명"으로만 적고, 집단별로 따로 적습니다.
- 같은 곳에서 2명 이상 막히거나 같은 오해가 2명 이상이면 **검토 후보**로 올립니다.
