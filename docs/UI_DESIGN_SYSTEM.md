## 0. 적용 전 진단 (2026-09-24 빌드 기준, 2026-09-25 적용으로 해소)

이 절은 이 문서가 왜 생겼는지의 기록이다. 아래 약점은 이번 적용으로 해소했다.

### 강점 (유지)
1. **지도가 주인공이다.** 플레이 화면에서 지표 HUD가 카드 없이 텍스트 행으로 씬 위에 바로 올라가 있고, 조작부는 네 모서리에만 있다. 화면 중앙 60% 이상이 3D 씬이다.
2. **데이터가 월드에 들어가 있다.** 보건지소 말풍선의 칸 5개, 창에 켜진 불, 길 위의 빛, 흰 점선 경계가 모두 "진료일/접근성"을 월드 안에서 보여준다.
3. **정직한 정보 표기.** 실제(실선)/가정(점선) 구분, 기준선 대비 증감, 자료 기준일, 자료와 한계.

### 약점 (해소)
1. 표면이 세 종류(어두운 HUD, 청록 강조 사이드 패널, 크림 종이 패널)로 갈라져 있었다 → §5 표면 3종으로 통합.
2. 증감 표기에서 화살표와 부호가 반대 방향을 가리킬 때가 있었다(▲ −4.8일) → §9.1 증감 문법.
3. 주 CTA가 화면마다 채움/외곽선을 오갔고, 월드 피드백 숫자가 판 없이 지형과 겹쳤다 → §7 Primary 하나, §8.3 판 위 피드백.

## 2. 디자인 원칙과 시각적 성격

**성격 한 줄**: 밤의 지형 모형 위에 놓인 실험 노트. 조용하고, 숫자가 정확하고, 빛은 데이터가 있을 때만 켜진다.

1. **씬 우선.** 플레이 중 상시 UI는 뷰포트의 가장자리 슬롯(§8.1)에만 선다. 자세한 정보가 필요하면 씬을 옆으로 밀고(지표 자세히 Sheet, 카메라가 남은 영역으로 재프레이밍) 씬 위를 덮지 않는다.
2. **빛은 데이터다.** 호박색은 "진료가 닿음"과 진료일에만 쓴다. UI 장식, 버튼 글로우, 강조 테두리에 쓰지 않는다.
3. **한 화면에 하나의 질문.** 각 단계(튜토리얼, 배치, 결산, 비교)에 화면이 답할 질문이 하나 있고, 그 답이 가장 크게 보인다(예: "주 1.2일", "미달 · 가능한 배분 중 상위 26%").
4. **실제와 가정은 섞어 보이지 않는다.** 실선 = 실제 자료, 점선 = 가정·미리보기. 이 문법은 배지·미리보기 판·손의 말에 공통이다. (말풍선의 칸은 실제/가정을 나누지 않는다 — §8.2)
5. **장식보다 정렬.** 구분은 카드가 아니라 정렬선, 1px 규선, 여백으로 만든다.
6. **톤**: 존댓말 평서문, 짧게. 감탄사·이모지·과장 없음. 결과는 판정이 아니라 사실로 쓴다. 금지어는 설계안 5-12.

- 한 화면의 채도 있는 색은 amber + good/bad(+ 결산의 loss 표지)가 최대. 새 액센트를 추가하지 않는다.

## 4. 타이포그래피

### 4.1 Font stack
- UI 전체: `'Pretendard Variable', 'Pretendard', -apple-system, 'Apple SD Gothic Neo', 'Noto Sans KR', 'Malgun Gothic', system-ui, sans-serif` (`--font`, `--display`도 같은 값)
- 한 가지 패밀리만 쓴다. 세리프(Hahmlet)는 **지도에 새겨진 읍·면 지명(캔버스, `stage/engraved.ts`)** 에만 쓴다. HUD·패널·제목에 세리프 금지.
- 모노스페이스를 쓰지 않는다(숫자 정렬은 tabular-nums).

### 4.2 Scale (px, 1440 기준 데스크톱)

| 토큰 | 크기/행간 | 굵기 | 용도 |
|---|---|---|---|
| `display` | 40/50 | 700 | 시작 화면 질문 두 줄(그 위 사실 한 줄은 20/28 · 600) |
| `hero-num` | 36/40, 단위 20 · 600 | 700 | 미션 현재값 "주 **1.2**일" |
| `verdict` | 30/38 | 700 | 세계 위 결산 판정 문장 |
| `title` | 20/28 | 700 | 시트 제목, 월드 피드백 숫자, 시트 안 판정 |
| `body-strong` | 15/22 | 600 | Primary 버튼, 튜토리얼 본문 |
| `body` | 14/20~22 | 400–500 | 설명, 표 셀, HUD 지표 값(14/600) |
| `label` | 13/18 | 500–600 | 지표 이름, 말풍선 이름, 툴팁, 증감 |
| `meta` | 12/16~18 | 400–600 | 기준일, 범례, 태그, 표 머리 |

- 최소 12px. 예외: 11px = 미션 지표 태그·미션 2 읍·면 막대 이름, 10px = 세 배분 나란히의 지소 약칭 줄.
- 씬 위 직접 텍스트는 13px 이상. 12px은 가장자리 scrim 안의 메타(기준일·손 아래 분해 설명·범례)만.
- 굵기는 400 / 500 / 600 / 700 네 단계만.
- 숫자와 단위, 질문의 어절은 줄에서 끊지 않는다(시작 화면 "주 10일.", "5일이 더 생긴다면 / 어디에 두시겠어요?").

### 4.3 숫자 표현
- 모든 수치는 tabular-nums. 시트 표의 숫자 열은 오른쪽 정렬.
- 천 단위 쉼표(24,846명). 진료일 소수 한 자리(주 1.2일, 목표 바로 아래 미달은 두 자리 0.99). 퍼센트 정수(47%).
- hero 숫자는 단위를 작게: "주 **1.2**일".
- 마이너스는 −(U+2212). 반올림해 0이면 단위 없이 `±0`.
- 범위는 현재 문구대로 물결표 `3~5일`, `10~15분`(en dash로 바꾸지 않았다 — §15).

## 5. 표면 체계

세 가지만 있다. 새 표면을 만들지 않는다.

| 표면 | 모습 | 쓰는 곳 | 금지 |
|---|---|---|---|
| **HUD** | 배경 없음. 텍스트가 씬 위에 바로, 뒤는 가장자리 scrim | 플레이 중 왼쪽 위 목표·6개 지표, 오른쪽 위 도구, 아래 가운데 손, 오른쪽 아래 확정, 결산·S6의 세계 위 결과 글 | 카드 테두리, 블러 판, 글자 그림자 |
| **Sheet** | `--sheet-bg` 불투명. 가장자리에 붙는 시트는 모서리 0, 떠 있는 판은 4px | 지표 자세히, 결과 자세히, 세 배분 나란히(오른쪽 판), 지역 카드, 읽는 법 범례, 미리보기·결과 판, 툴팁 | 반투명·블러 |
| **Paper** | `--paper` 불투명, 6px | 자료와 한계 모달 전용 | 게임 흐름 안의 패널에 사용 |

- 게임 흐름 안에서 밝은 면을 열지 않는다(결과 자세히·세 배분 나란히도 어두운 Sheet).
- Sheet 안의 하위 그룹은 박스가 아니라 **소제목 + 24px 여백 + 1px 규선**으로 나눈다(얻은 것/잃은 것은 두 열 텍스트).
- 예외: 미션 브리핑(S3)은 흐름을 잠시 멈추는 한 장이라 가운데 Sheet(4px, 뒤는 night 60%)로 선다.

## 6. Spacing / Border / Radius / Shadow / Opacity

### 6.1 Spacing (8px 기반)
`4 · 8 · 12 · 16 · 24 · 32 · 48 · 64`
- 4는 아이콘-텍스트, 배지 내부 같은 미세 간격에만.
- 화면 안전 여백: 1280 이상 40px, 1279 이하 24px.
- 행 높이: HUD 지표 28px, 세계 위 결산 표 32px, S6 세계 표 34px, 시트 표 36px.
- 그룹 간 24, 섹션 간 32–48.

### 6.2 Border / Radius — 역할에 따라 다르게

| 요소 | Radius |
|---|---|
| Primary 버튼 | 높이의 50%(필) |
| 아이콘 버튼 | 원형 |
| 세그먼트(10/15/20분, 지도 증감 기준) | 트랙 필 + 칩 필 |
| 말풍선 | 8px + 꼬리 |
| 배지·태그(실제/가정, 미션 지표, 도로망 시간, 잃은 마을, 판정 칩) | 2px |
| Sheet 안 판 · 툴팁 · 미리보기/결과 판 · 입력(select) · Quiet box | 4px |
| 가장자리 Sheet | 0 |
| Paper 모달 | 6px |

- 데이터 배지(설계안 8-2)의 세 모양: 실제 자료 = 실선 테두리, 계산값 = 실선 테두리 + 빈 사각(□), 게임 가정 = 점선 테두리. 모두 2px 태그.
- 테두리는 1px. 2px는 선택/포커스 링, 목표 지표 왼쪽 선, "가장 불리한 읍·면" 점선에만.
- 점선은 **가정·미리보기·참고 배분**과 **가장 불리한 지역**의 뜻에만 쓴다. 장식용 점선 금지. 튜토리얼이 가리키는 곳도 크림 점선 하이라이트다.

### 6.3 Shadow / Scrim
- UI 그림자는 기본적으로 없다. 말풍선·도로망 시간 태그·잃은 마을 표지에만 `0 1px 2px` 접지 그림자. 손의 나무 말(게임 자원)만 3D 질감 그림자를 허용한다.
- 씬 위 텍스트 가독성은 **scrim**으로 해결한다: 화면별로 HUD가 서는 가장자리에서 안쪽으로 사라지는 night 45~85% 그라데이션(`world.css`의 `.stage-vignette`). 블러 금지.
- 모달·브리핑 뒤 딤: night 60%. 블러 없음.

### 6.4 Opacity
- 사용 단계: 100 / 72(나란히 보기에서 고르지 않은 열) / 40(비활성) / 12(규선).
- 텍스트 위계는 알파가 아니라 `--text-2`, `--text-3` 실색으로 준다.

## 7. 버튼과 상태

### 7.1 종류

| 종류 | 모습 | 화면당 | 예 |
|---|---|---|---|
| **Primary** | cream 채움 필, cream-ink 15/600, 높이 48(튜토리얼·소개 카드 안 40). 시작·확정·다음 미션·처음으로는 끝에 → 선 아이콘 | **정확히 1개**(해당 단계의 다음 행동) | 시작, 배분 시작, 이 배분으로 확정, 다음 미션, 처음으로 |
| **Secondary** | 텍스트 + 1px 밑줄(흰색 45%), 14/500 | 여러 개 | 다시 배분, 결과 자세히, 자료와 한계, 건너뛰기, 세 배분 나란히 보기 |
| **Quiet box** | 1px `--edge` 테두리, 4px, 높이 32, 13/500 | 시트 내부 | 닫기, 낮은 순/이름순, 읽는 법, 시트 안 토글 |
| **Icon** | 44px 원형 cream 면, 20px 아이콘 | 오른쪽 위 도구군 | 되돌리기, 위에서 보기(◇), 지표 자세히(≡), 소리 |

- "이 배분으로 확정"은 늘 Primary 채움이다. 남은 진료일이 있을 때만 비활성이고, 그 아래 "남은 N일을 모두 놓으면 확정할 수 있어요" 한 줄이 이유를 말한다.
- Secondary를 필/박스로 만들지 않는다.
- 아이콘 버튼은 `aria-label`과 hover 툴팁(한국어 동사 + 있으면 단축키, 예: "되돌리기 Ctrl Z")을 함께 가진다.

### 7.2 상태

| 상태 | 규칙 |
|---|---|
| hover | Primary/Icon: 면 `--cream-hover`. Secondary: 밑줄 1→2px, 흰색 100%. Quiet box: 면 `--sheet-row` + 테두리 `--edge-3`. **크기 변화·이동·그림자·글로우 금지**. 전환 100ms |
| pressed | Primary/Icon: 면 `--cream-press`. Secondary: 글자 `--text-2`. 이동·축소 없음 |
| focus-visible | 2px cream 링 + 2px 오프셋(필·원은 3px). Paper 위에서는 cream-ink 링. 마우스 클릭에는 표시 안 함(`:focus:not(:focus-visible)`) |
| selected(토글) | Icon: night 면 + cream 2px 테두리 + cream 아이콘. 세그먼트: cream 칩. Quiet box: cream 테두리. 소리 끔 상태도 Icon selected 모양 |
| disabled | 불투명도 40%, 커서 기본. 세그먼트가 잠기면(결산·S6) 트랙 전체 40% |

## 8. HUD · 월드 공간 UI

### 8.1 HUD 슬롯 (고정 위치)

| 슬롯 | 내용 | 규칙 |
|---|---|---|
| 왼쪽 위 | 미션명 → hero 현재값 + 오른쪽 "목표 주 2.8일" → 2px 목표 진행선 → 상태 한 줄(+ 미리보기 점선 태그) → 6개 지표 표 → 범례 → Secondary 링크(지표 자세히 · 증감 보기) | 폭 336px(1279 이하 300, 1099 이하 250). 튜토리얼·소개에서는 같은 자리에 단계 카피. 미리보기 태그 자리는 미리보기가 없을 때도 비워 둔다(말풍선을 가리킬 때마다 아래 표가 움직이지 않게) |
| 오른쪽 위 | "닿는다고 볼 시간" + 10·15·20분 세그먼트 + 아이콘 버튼군 | 한 줄, 묶음 간격 16, 아이콘 간격 12. 지표 자세히가 열리면 시트 왼쪽으로 비켜 선다 |
| 아래 가운데 | 남은 진료일(나무 말 + ×N 30/700 + "남은 진료일") │ 실제/가정 태그 + "실제 10일 + 가정 5일" | 게임의 "자원" 슬롯. 말만 3D 질감 |
| 오른쪽 아래 | Primary + 이유 한 줄 | |
| 왼쪽 아래 | 읽는 법(Quiet box) + 자료 기준일 메타 + 자료와 한계 링크 | 읽는 법 범례는 열릴 때만 Sheet 재질로 위에 |
| 가운데 위 | 기준 변경 소식 한 줄(Sheet 판, 3.2초) | 설계안 6-17 |

- 슬롯 밖에 새 UI를 띄우지 않는다. 새 정보는 기존 슬롯 안에 넣거나 Sheet로 연다.
- HUD 6개 지표는 **표 한 개**다. 행마다 카드·아이콘을 달지 않는다(지표 자세히 시트에도 행 아이콘 없음).

### 8.2 월드 공간 라벨 (보건지소 말풍선, `ui/Markers.tsx`)
- 구성: 이름(13/600) + 칸 5개(11px 원, 간격 3). 채운 칸 = 진료일 1(amber + `--amber-deep` 테두리), 반 칸 = 격주, 빈 칸 = 1px 테두리. **칸은 실제/가정을 나누지 않는다**(어느 지소의 날이 실제·가정인지는 뜻이 없다, 설계안 6-17 기각·변형 ③). 실제/가정 구분은 손·브리핑·결산의 태그가 맡는다.
- 놓일 칸(미리보기)은 옅은 amber + 점선, 빠질 칸은 코랄 점선. 비교 배분(참고·앞 미션·현재 실제)은 칸 둘레의 옅은 실선 고리.
- 크기는 카메라 거리와 무관하게 **화면상 고정**, 판 높이 28px.
- 진료일이 있는 지소에는 판 오른쪽에 "−" 칸이 붙는다(세로 규선으로 나뉨, 누르는 자리 32px).
- 상태: 기본 = cream 판 · 가리키기/미리보기/키보드 선택 = 판이 뒤집힘(night 면 + cream 테두리) · 키보드 포커스 = 2px cream 링 · 튜토리얼 대상 = cream 점선 · 막 앉음 = 판 밝기 한 번 · 막힌 조작 = 옆으로 2px 한 번.
- 겹침: 화면 앞(아래)의 말풍선부터 놓고, 겹치는 뒤쪽 말풍선은 줄기를 늘려 위로 든다. 미리보기·결과 판을 띄운 말풍선은 이웃 말풍선 위에 그린다. 화면 밖으로 나간 말풍선만 숨긴다.

### 8.3 월드 피드백
- **놓기 전(미리보기)**: 말풍선 오른쪽(화면을 넘치면 왼쪽)에 **점선 판**(Sheet 면, 4px, 최대 폭 300). "계룡에 1일 놓으면 [미리보기]" → 숫자(20/700 amber, 빼기는 코랄) + 한 줄 → 규선 → 바뀌는 값(지소 진료일 · 미션 지표) → "클릭해서 놓기 · Esc 취소"(되돌리기에서 온 미리보기는 "누르면 되돌려요 · Ctrl Z"). 같은 값이 왼쪽 위 hero 아래 점선 태그 "미리보기 → 주 1.2일"로도 보인다. 숫자는 실제 계산값이고 놓은 뒤 결과와 같다.
- **놓은 뒤(결과)**: 말풍선 위 8px에 앵커한 **실선 판**(Sheet 면 + `--edge` 테두리, 4px) + 1px 줄기. 숫자(20/700) + 한 줄 설명(12). 1.9초 뒤 사라지고, 다음 조작 때 교체된다(쌓이지 않음).
- 실선 = 확정, 점선 = 미리보기 — 실제/가정 문법과 같다. 판 없이 지형 위에 직접 쓰지 않는다.
- 결산의 잃은 마을 표지: loss 판(2px) + 흰 글자 13/600, 많아야 셋 + "외 n곳".

### 8.4 툴팁 / 컨텍스트 UI
- 아이콘 버튼 툴팁: `--tip` 판, 4px, 13px, hover·키보드 포커스 400ms 뒤 160ms에 나타난다.
- ⓘ 정보: 지표 자세히 시트에서 지표 이름 바로 옆. 누르면(토글) 그 행이 `--sheet-row`로 밝아지고 설명 판(최대 280px)이 다음 행 위에 뜬다. 한 줄에 둘 이상 금지.
- 도로망 시간 태그: cream 판 + cream-ink, 2px, 12/600, "산의리 · 도로망 15분". 지소를 가리키면 가장 먼 마을 셋까지, 마을을 가리키면 그 마을에 닿는 지소들. 다른 라벨과 겹치면 그 프레임에 숨긴다.

## 9. Metric / Progress / Result UI

### 9.1 증감 문법 (필수)
- **부호**는 값이 커졌는지 작아졌는지: `+0.7일`, `−6분`.
- **색**은 기준선 대비 좋아졌는지(good 파랑) 나빠졌는지(bad 코랄).
- **화살표는 쓰지 않는다.** 뜻은 범례("현재 실제(10일) 대비 ■좋아짐 ■나빠짐", 기준선이 앞 미션이면 "미션 n 배분 대비")와 화면 낭독용 낱말이 말한다.
- 이 규칙은 화면 UI의 증감 글자에 적용한다. 세계의 증감 모드 ▲▼ 깃발(설계안 6-16, 3D 무대의 데이터 채널)은 세계 표현이라 이 문서 범위 밖이다.
- 변화 없음: `±0`, `--text-3`.
- 예: 90% 접근시간 22분→16분 = `−6분` 파랑. 평균 진료일 2.1→1.2 = `−0.9일` 코랄.

### 9.2 지표 행
- HUD: 이름(13/500, text-2, 넘치면 말줄임) · 값(14/600, text) · 증감(13/600, 72px 오른쪽 정렬), 열 간격 10.
- 미션 목표 지표는 이름을 굵게(700, text) + 왼쪽 2px cream 선. "미션 지표" 태그는 지표 자세히 시트의 그 한 행에만(세 배분 나란히의 열에서는 짧은 "목표" 태그).
- 지표 자세히 시트: 머리(이름 + ⓘ + 태그 … 증감) → 값 20/700 → 보조 12 text-3.

### 9.3 진행
- 목표 진행선: 2px 트랙(흰색 18%) + cream 채움 + 목표 지점 세로 눈금(2×10px). 높이를 키우지 않는다.
- 분포 막대(90% 접근시간의 10·15·20분 구간): 한 줄 스택 6px, 구간 라벨은 아래 meta.
- 원형 게이지, 도넛, 퍼센트 링 금지.

### 9.4 결산 / 결과
- 세계 위 결산(S5) 위계: 미션명(13/600) → 판정 문장(30/700 "미달 · 가능한 배분 중 상위 26%") → 한 줄(목표 기준과 비교 대상) → 6개 지표 표(지표 · 현재 실제 · 내 배분 · 차이) → 잃은 것(라벨 "잃은 것" + 코랄 문장 + 마을 이름) → 실제/가정 태그 + 15일 기준 문장 → Primary 1 + Secondary.
- 판정에 등급 아이콘, 별, 트로피, 색 배너 금지. 문장과 숫자로만.
- 비교표(S6 세계 표, 세 배분 나란히 시트): 열 = 미션, 행 = 지표. 고른 열은 머리에 2px cream 밑줄, 각 미션이 목표로 삼은 칸만 굵게 + cream 1px 테두리. 범례 "테두리 칸 = 그 미션이 목표로 삼은 지표". 배경색 채움 칸 금지.
- "잃은 것"은 표·문장과 세계의 빨간 표지가 1:1로 대응한다.

## 10. Card / Panel / Modal

- **카드는 기본값이 아니다.** 세 배분 나란히 보기의 세 미션 열(각자 미니 지도)이 유일한 정당한 경우다: 4px, 1px 규선, 가리키는 열만 cream 1px, 나머지 열 72%.
- **Sheet**: 지표 자세히는 오른쪽 380px, 결과 자세히·세 배분 나란히는 폭 480(1440 이상) / 440 / 400. 열리면 카메라가 남은 영역 중심으로 재프레이밍한다. 닫기는 오른쪽 위 Quiet box + Esc. 닫힌 Sheet는 DOM에서 뺀다.
- **Modal**: 게임 흐름을 멈춰야 하는 문서(자료와 한계)만. 최대 폭 880px, Paper, 내부 스크롤, Esc/딤 클릭으로 닫기, 열면 닫기 버튼으로 포커스, 닫으면 연 자리로 포커스를 돌려준다.
- 확인 다이얼로그는 쓰지 않는다. 되돌리기가 있으므로 즉시 실행 + 되돌리기.
- 튜토리얼(S2)은 모달이 아니라 왼쪽 위 슬롯의 단계 카피 + 진행 막대(3칸) + Primary [다음] + Secondary [건너뛰기]. 가리키는 대상은 세계의 점선 하이라이트.

## 11. Transition / Microinteraction

| 종류 | 시간 | 규칙 |
|---|---|---|
| hover/pressed | 100ms ease-out | 색·밝기만 |
| 툴팁 | 400ms 지연 뒤 160ms | 불투명도만 |
| 미리보기·결과 판 등장 | 160ms | 불투명도 + 4px 이내 이동 |
| Sheet 열기 | 240ms 감속 | 가장자리에서 24px 미끄러짐, 카메라 재프레이밍과 동시 |
| 결산 진입 | 감상(카메라가 섬을 약 4.2초 돈다, 누르면 바로) → 결과 글 400ms 페이드 | 카메라 이동이 주연 |
| 수치 변화 | 빛을 따라(설계안 6-16: 계산은 즉시, 표시는 빛이 닿는 순서대로) | 판정값·증감은 빛이 다 닿은 뒤 정확한 값 |
| 월드 빛(창·길) | 씬 담당 | UI 애니메이션과 동시에 튀지 않게 순차 |

- 모든 움직임에는 원인이 있어야 한다(사용자 행동 또는 데이터 변화). 대기 중 반복 애니메이션 금지(말 흔들림·칸 숨쉬기·코치 깜빡임 없음).
- 스프링·바운스·오버슛·도장 찍기 금지.
- `translate`로 가운데를 맞춘 요소(말풍선·잃은 마을 표지 등)에 `translate` 키프레임을 `both`로 걸면 끝 프레임이 맞춤을 덮는다. 키프레임에 맞춤값(`-50%`)을 함께 넣거나 `transform`으로 움직인다.

## 12. 입력 · 접근성 · 반응형

### 12.1 히트 영역
- 데스크톱 최소 32px을 목표로 한다(− 칸, ⓘ는 보이는 크기보다 넓게 잡는다). 밑줄 링크 일부는 아직 글자 높이뿐이다(§15).
- 지도 위 보건지소는 말풍선과 건물 모두 반응한다. 드래그(카메라 회전)와 클릭(배치)은 5px로 가른다.

### 12.2 키보드
- Tab 순서: 보건지소 말풍선 10곳(서쪽 → 동쪽) → 오른쪽 위 도구 → 왼쪽 아래 → 왼쪽 위 HUD → 확정.
- 말풍선: `+` `=` `→` Enter Space = 1일 놓기, `−` `_` `←` Backspace Delete = 1일 빼기, `↑` `↓` Home End = 옆 지소. 포커스를 받으면 미리보기가 뜬다. Ctrl/Cmd+Z = 되돌리기.
- Esc: 세 배분 나란히 → 지표 자세히 → 감상 건너뛰기 → 미리보기·지역 카드 순으로 닫는다. 자료와 한계 모달은 자기 Esc를 가진다.
- 라이브 영역: 조작마다 한 문장(정확한 값). 조작 직후 다음 프레임에 들어온다.

### 12.3 Reduced motion
- `prefers-reduced-motion`에서 카메라 이동은 컷, 불씨 비행·감상 없이 결과로, CSS 애니메이션·전환은 사실상 0.
- 소리는 첫 입력 전에는 나지 않고, 끄기 상태는 저장된다.

### 12.4 반응형
- ≥1280: 현재 레이아웃.
- 1024–1279: 같은 배치, 여백 24, HUD 폭 300, 세그먼트 라벨·기준일 칩 숨김, 결산 판정 26px.
- 768–1023: 설계안의 남은 과제(시트형 배치)다. 지금은 1024 규칙에 HUD 폭 250, 아이콘 40px, 이유 한 줄·마무리 문장을 숨긴다.
- <768: 게임 대신 안내 화면과 자료와 한계(설계안 5-10, 모바일은 MVP 범위 밖).

## 13. WebGL 성능 규칙

1. **DOM 월드 라벨 수 상한.** 말풍선 10 + 잃은 마을 표지 ≤3 + 미리보기·결과 판 1~2 + 도로망 시간 태그 몇 개. 마을 이름 라벨은 확대 2.2배 이상에서만 HTML로 만들고 우선순위 컬링으로 겹치는 것을 숨긴다(§15).
2. 라벨 위치 갱신은 `transform`만. top/left, width 변경 금지.
3. `backdrop-filter`, 큰 `filter: blur`, 큰 box-shadow를 캔버스 위에 두지 않는다(현재 없음).
4. 수치 변화는 텍스트 교체만(tabular-nums).
5. 카메라/프레임 값은 React state에 넣지 않는다. HUD는 배분·지표가 바뀔 때만 렌더.
6. 닫힌 Sheet는 DOM에서 제거한다.
7. 측정: 배치 클릭 → 피드백 → 빛 전파 구간을 DevTools Performance로 기록해 60fps(저사양 30fps) 유지를 확인하고, spector.js로 UI 변경이 드로콜을 늘리지 않는지 확인한다(§15 — 전시 기기 실측 전).
8. Pretendard는 dynamic subset + `font-display: swap`.
